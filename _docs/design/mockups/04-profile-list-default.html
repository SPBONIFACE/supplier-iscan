Behaviour and accessibility

  • Rows: the supplier name opens the supplier card (#5); the status link of a running, stopped or failed run opens its run progress page.
  • Selection for comparison: ticking a row adds the cobalt-tint background, the 3px cobalt bar and the checked box (brief § 9). “Compare selected” needs two or more ticked profiles. Runs without a profile cannot be ticked; the reason is given to screen readers.
  • Column headers are sort buttons; the sorted column carries aria-sort. The header row is sticky.
  • Below 760px the table becomes one block per profile with inline labels, so there is no horizontal scroll.
  • Values in ‹…› are configured by the instance (quota, access end date); the mock-ups show no product numbers.
  • Flags reuse the flag-banner shape (paper-margin, 4px ink left rule) as a micro-label: “partial”, “identity to verify”, “insufficient sources”. No flag means nothing is drawn.

For the owner

  • Run status labels in the list (“Run in progress: collection”, “Complete”, “Ended without a profile”, “Stopped”) are not in the approved status vocabulary of #3; proposed here, French included.

All organisations, suppliers, people, domains (*.example) and identifiers are fictional. Values in ‹…› are configured by the instance.
