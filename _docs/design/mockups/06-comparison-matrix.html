Keyboard focus order

Black numbered markers on the screen show the sequence of Tab stops; the list groups them.

  1. Skip to content (first stop, visible on focus).
  2. Top bar: Supplier profiles, New profile, Organisation; language EN/FR; Sign out.
  3. Page actions: Change selection, then Download PDF.
  4. Column headers, left to right: Open card, then Remove, for each profile.
  5. The comparison grid is one Tab stop (roving tabindex): Tab lands on the last focused cell, the first value cell the first time.
  6. Inside the grid: ← → move between profiles in a row, ↑ ↓ between fields; Home/End first/last profile of the row; Ctrl+Home/End first/last cell; Page Up/Page Down previous/next section. Moving focus scrolls the cell into view; the field column stays sticky.
  7. Enter on a cell moves focus to its source chip; Tab then reaches the next control in the cell (Verify on IAF CertSearch, Details). Enter/Space on the chip opens the Quote under the value; Escape closes it and returns focus to the chip, a second Escape returns to the cell.
  8. Tab out of the grid: footer links (Privacy notice, Legal notices, Crawler contact).

Annotations

  • From 5 profiles up to the configured maximum, the comparison switches to this compact matrix: narrower columns (176px), shorter column headers, bylines moved into the card; status and source chip stay in every cell.
  • Only profiles of the member’s own Organisation can reach this screen; an identifier from another organisation returns the not-found page (404, no existence leak).
  • Each value keeps its source chip and its review status. Missing values keep the full wording “No public evidence found” in brick; certification fields keep “Verify on IAF CertSearch”.
  • Review (approve, correct) is done in the supplier card, not in the comparison; “Open card” opens it in the side panel.
  • Evidence status (source type, Redacted extract) stays in the Quote’s source line; review status stays next to the chip.
  • Selected or focused row: cobalt tint. Focused cell: 2px cobalt outline inside the cell.
  • At 400px the page does not scroll sideways: the table scrolls inside its own frame and the field column (128px) stays sticky.
  • Footer: the privacy-notice and legal-notices links appear in the footer of every page (members, administrators, demo and public pages, issue #7). Document texts are owner-supplied (#41).
