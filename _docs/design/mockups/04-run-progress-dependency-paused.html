Behaviour and accessibility

  • The stage list shows identity → collection → extraction → assessment; the current stage carries aria-current="step" and a stronger rule beneath it. Stage states are words (micro-labels), never colour alone. There is no animated spinner.
  • The summary sentence above the stages is a polite live region, so stage changes are announced.
  • The side column (paper-margin, 300px) holds the organisation quota and the run details; below 960px it moves under the main column.
  • Failure log columns follow spec § F2: each failure with the strategy tried and the next strategy chosen. Below 760px each entry becomes a block with inline labels.
  • The error banner (role="alert") names the dependency in plain language and says whether the run is paused and can be resumed (spec § Robustness cases).
  • Errors are ink with an “Error:” prefix, never brick.
