Mock-ups: workspace, new profile with identity chat, run progress

31 screens and states · static HTML, no build step · built only from the tokens and components approved in #3 (_docs/design/brief.md, tokens.json)

How to read these files

  • Open any file in a browser; it needs only tokens.css next to it (generated from _docs/design/tokens.json).
  • Desktop at 1280px is the reference width; every screen also reads without horizontal scroll at 400px.
  • Each screen ends with mock-up notes: its keyboard focus order (also shown in place with “Show focus order”), behaviour and accessibility notes, and any question for the owner.
  • Values in ‹…› are configured by the instance (quota, access end date, attempt cap); no product number appears.
  • All data is fictional: organisations, suppliers, people, *.example domains and identifiers.
  • IBM Plex is loaded from Google Fonts in the mock-ups only; the application self-hosts the fonts (#31).
  • The AI disclosure texts are taken verbatim from spec § F1, English and French.

Questions for the owner

  • Run status labels in the list (“Run in progress: collection”, “Complete”, “Ended without a profile”, “Stopped”) are not in the approved status vocabulary of #3; proposed here, French included. (Profile list)
  • Is the language choice the language of the profile only, or also the UI language for this session? The mock-up labels it “Profile language” (spec Flow 1 step 2 says “the language”). (New profile)
  • French term for “Profile run”: the French mock-ups use « analyse » (« lancer l’analyse »). Please confirm. (Identity chat, top candidate)
  • The spec’s French disclosure uses a regular space before “:” and straight apostrophes; it is reproduced verbatim. A typographic version (non-breaking space, curly apostrophe) would need the spec text to change. (Identity chat, confirm the Identity record)
  • Does a stopped run count against the quota? The spec does not say; the mock-up states nothing about it. (Run progress, stop confirmation)
  • Is anything kept from a stopped run (sources collected so far)? The wording only says the run cannot be resumed. (Run progress, stop confirmation)
