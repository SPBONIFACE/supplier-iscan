Behaviour and accessibility

  • The AI disclosure is the first turn of the conversation, in the UI language, verbatim from spec § F1, before any input.
  • The transcript is an ordered list with role="log", so each new assistant turn is announced politely. Turns are typeset as a transcript (speaker micro-label, time), not as chat bubbles.
  • Candidates are compact definition lists: name, website, country, sector, one-line description, and the line saying where they were found. No score or percentage is shown (the IdentityProposal confidence is never displayed).
  • Only the latest assistant turn carries action buttons; earlier turns keep their text only.
  • After an action, focus moves to the heading or first paragraph of the new assistant turn.
  • While the domain is checked, “Checking…” follows the field and the field stays editable (brief § 7.7, loading).
  • The error is inline in the conversation, never an error page.
